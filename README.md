# Mauro Developer — Full Stack Portfolio

Uma landing page moderna e cinematográfica desenvolvida para apresentar minha identidade como desenvolvedor full stack, destacando projetos, experiência com APIs, arquitetura de sistemas e aplicações modernas de alta performance.

---

## Tecnologias

Este projeto foi desenvolvido utilizando tecnologias modernas do ecossistema React:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

---

## Design & Experiência

A aplicação segue um visual moderno inspirado em interfaces premium, utilizando:

- Tema dark cinematográfico
- Contraste preto + laranja
- Layout responsivo
- Microinterações
- Transições suaves
- Scroll fluido
- Componentização profissional
- Glow effects e depth UI

## Instalação

Clone o projeto:

```bash
git clone https://github.com/MauroSantosIf/ft_lading_page.git
```

Entre na pasta:

```bash
cd ft_lading_page
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
